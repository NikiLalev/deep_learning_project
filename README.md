## Habrok Training

This repository contains the training, testing, and evaluation pipeline for the object detection model.

---

### Scripts

#### Dataset Download

* **`download_data.sh`**

  Downloads and prepares the dataset.

  Executes:

  `download_data.py`

#### Training

* **`submit_training_detection.sh`**

  Submits and runs the training loop.

  Executes:

  `train_habrok_detection.py`

#### Testing

* **`submit_testing_detection.sh`**

  Submits and runs the testing script.

  Executes:

  `test_script_detection.py`

---

### Evaluation

Evaluation is performed **locally** using the output generated by the testing script.

* The testing phase produces a `results.json` file.
* This file is then used to:
  * generate plots (loss curves, calibration plots)
  * compute evaluation metrics (mAP, size-based mAP, ECE)

---

### Typical Workflow

1. Download and prepare the dataset: `download_data_detection.sh`
2. Train the model: `submit_training_detection.sh`
3. Test the trained model: `submit_training_detection.sh`
4. Run evaluation locally on `results.json`. uses the `plot.py` script
